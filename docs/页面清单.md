# 页面与截图清单

来源：Pixso `UI Kit_DeliWell` → `Page 1`；`Symbols` 为共享组件库，不作为独立业务页面。

编号与原稿导出保持一致。空白/填写/展开/弹层是同一页面的不同状态；截图测试通过构造参数呈现状态，正常应用中通过按钮、输入和筛选操作进入。

截图由 Android 模拟器中的 Flutter 渲染表面直接导出，不包含 Android 系统状态栏。截图不修改本地保存的数据。

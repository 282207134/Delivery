## 测试范围与限制

- 界面巡检与文本输入流程最终在 Android 模拟器上执行。本机 Windows 的 `flutter_tester` 在批量图形/输入测试中曾出现原生进程异常，因此交付测试将图形及输入验证统一放在 Android 集成测试，普通 `flutter test` 保留稳定的业务测试。
- iOS 工程已提供，未在 iOS 模拟器/真机上验证；Web 工程已提供，未进行浏览器交互验收。
- 无真实短信、支付、地图定位、推送、库存或物流接口；订单进度和配送员为本地演示数据。
- 取消订单、删除收藏箱和移除本地账户提供确认弹窗；这些操作只作用于演示应用本机存储。
- 安装包为开发签名的本地验收版本，不应直接作为应用商店正式发布版本。

## 复现

```powershell
flutter pub get
flutter analyze
flutter test
flutter drive -d emulator-5554 --driver=test_driver/screenshots.dart --target=integration_test/screenshots_test.dart
flutter build apk --release --split-per-abi --target-platform android-arm64,android-x64
```

`docs/test-output.txt` 保存业务测试结果；`docs/analysis-output.txt` 保存静态检查结果。安装包与源码压缩包见根目录 `releases/`。
